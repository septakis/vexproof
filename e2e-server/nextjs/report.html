Method

Each advisory reported against the dependency lockfile is checked against what actually ships. A statement is marked not affected only when it can be shown mechanically: either no component of that package appears in the SBOM generated from the production build, or the package is present but none of the files containing the vulnerable code survived bundling, according to the bundler's own module graph and a published per-advisory rule. Anything else stays open for human review. Reviewed decisions record who made them.
